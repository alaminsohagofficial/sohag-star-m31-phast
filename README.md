# SOHAG-Star-M31-PHAST

Photometric and astrometric candidate investigation in the Andromeda Galaxy (M31) utilizing Hubble Space Telescope (HST) PHAST survey datasets.

## Research Objective
To identify, filter, and analyze stellar candidates in M31 through high-precision photometric and astrometric modeling, applying noise-reduction methodologies to dense astronomical catalog data.

## Key Features
- **Catalog Ingestion & Filtering:** Automated parsing of multi-band HST PHAST photometric measurements.
- **Astrometric Validation:** Proper motion and positional cross-matching to isolate high-confidence candidates.
- **Data Visualization:** Color-magnitude diagrams (CMDs) and spatial distribution plots.

## Tech Stack
- **Language:** Python
- **Domain:** Computational Astrophysics, Statistical Modeling, Noise Filtering
